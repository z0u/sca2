# "cell" vs "condition" conflict with the glossary

Resolved the other way: "cell" collides with table/heatmap cells and Marimo cells, which can't be renamed, so prose now uses **condition** (seed-aggregated factor combination), **run** (condition × seed), and **criterion** (a hypothesis-gate clause), reserving "cell" for literal grid entities. Applied to ex-2.1.6/7/8 (where the old glossary lived); earlier reports already conformed. Scheme documented in the `style-terms` skill.
