# Survey-format lessons from ex-2.1.11, for the next search plan

Two frictions observed the first time the format ran. (a) A scalar objective walks to its constraint boundary: the proposed point passes the grading floor by 0.008, a third of that statistic's per-run σ, so a future plan should either freeze how close to a constraint a proposal may sit, or rank on constraint margins alongside the objective. (b) Promotion ranked on seed-0 values promoted two trials the task gate rejected at five seeds — the gate width (0.02) is only ~2× holdout EM's per-run σ (0.0087), so a single-seed pass near the boundary carries little information. Also: state in the plan that the publisher must carry every statistic the analysis sections promise (r2_cond had to be added post hoc, as a REVIEW-noted publisher extension).
